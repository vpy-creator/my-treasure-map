# My Treasure Map

Trang giới thiệu My Treasure Map của Vũ Phi Yên, EarthWise VN.

- `dau-cham-dau-tien/` · phiên bản thứ nhất, món quà "Dấu chấm đầu tiên: Bạn đang ở đây". Nhạc nền `nhac-nen.mp3` nằm cạnh trang.
- `backend/dau-cham-dau-tien.gs` · bản lưu của Apps Script nhận tấm thiếp về Google Sheet "My Treasure Map · Dấu chấm đầu tiên (món quà)" và gửi thư đúc kết.
- Phiên bản "Hỏi và Toàn thức trả lời" sẽ có thư mục riêng.
